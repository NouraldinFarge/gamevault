# Community expectations

GameVault discussions, issues, pull requests, reviews, and other project spaces should remain respectful, specific, privacy-conscious, and focused on verifiable technical behavior.

## Expected behavior

- Assume good intent while evaluating evidence critically.
- Explain user impact, tradeoffs, and trust-boundary consequences.
- Protect private information, credentials, personal paths, and software ownership rights.
- Use synthetic fixtures and procedural artwork when demonstrating behavior.
- Accept maintainer decisions about product scope, safety boundaries, and release claims.

## Unacceptable behavior

- Harassment, discrimination, threats, personal attacks, or deliberate disclosure of private information
- Uploading commercial game files, license material, private archives, credentials, or personal library databases
- Piracy-enabling requests or attempts to weaken explicit review, ownership, platform, archive, or operating-system boundaries
- Publishing a suspected vulnerability before a coordinated fix is available
- Spam, deceptive claims, or repeated off-topic promotion

## Enforcement

Maintainers may edit or remove content, close discussions, reject contributions, or restrict participation when behavior conflicts with these expectations. Decisions should be proportional, documented when practical, and centered on community safety and project integrity.

Use GitHub's reporting and blocking tools for harassment or platform abuse. Report security vulnerabilities through [private vulnerability reporting](https://github.com/NouraldinFarge/gamevault/security/advisories/new); do not include sensitive conduct or security details in a public issue.
