# Product-tour media

`gamevault-product-tour.mp4` is a 45-second silent walkthrough built from current synthetic preview captures. `gamevault-product-tour-poster.jpg` links to it from the repository README, and [`gamevault-product-tour-transcript.md`](gamevault-product-tour-transcript.md) provides the same sequence as accessible text. `archive-review-plan.jpg` shows the current file-diff freshness checkpoint, prerequisite-audit boundary, and persistent-operation evidence used by both assets.

The rendered media contains only fictional game names, procedural artwork, generic portable paths, and synthetic archive results. Rebuild it on Windows with:

```powershell
pwsh -NoProfile -File scripts/render-demo-video.ps1
```

Review every frame for private paths, commercial content, accurate labels, legibility, and current product behavior before committing the result.
